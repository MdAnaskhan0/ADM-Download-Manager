# Anas Download Manager (ADM)

An Electron + React desktop download manager starter for Pop!_OS and Ubuntu-based Linux.

## Included in this first full-project baseline

- Electron desktop shell with context-isolated preload bridge.
- React dashboard with dark/light theme.
- aria2 JSON-RPC engine for direct HTTP/HTTPS downloads.
- yt-dlp process integration for supported video/audio URLs.
- FFmpeg-based audio extraction through yt-dlp (`-x`).
- Download status polling, history persistence, pause/resume/cancel controls.
- Local browser bridge on `127.0.0.1:43821` with a pairing token.
- Chrome and Firefox extension source.
- AppImage and Debian packaging configuration.

## Requirements

- Pop!_OS / Ubuntu
- Node.js 20 or newer (recommended)
- npm
- aria2
- yt-dlp
- FFmpeg

Install system dependencies:

```bash
sudo apt update
sudo apt install -y aria2 ffmpeg pipx git build-essential
pipx ensurepath
pipx install yt-dlp
```

Install Node.js 20+ from the Node.js project or a trusted Linux package source if your distro repository provides an older release.

Verify:

```bash
node --version
npm --version
aria2c --version
yt-dlp --version
ffmpeg -version
```

## Run in development

```bash
cd anas-download-manager
npm install
npm run dev
```

Vite serves the React UI locally and Electron opens the desktop window.

## Build Linux packages

```bash
npm run dist:linux
```

Artifacts are written to `release/`. Linux packaging requires a suitable icon at `build/icon.png`; add a 512x512 PNG icon before packaging. You can temporarily remove `"icon": "build/icon.png"` from `package.json` if you do not have one yet.

## Browser extensions

Extension source is in `browser-extension/`.

1. Start ADM. Its local bridge listens only on `127.0.0.1:43821`.
2. Open ADM Settings and copy the Browser pairing token.
3. Load the matching extension folder as an unpacked extension.
4. Open extension Options and paste the pairing token.
5. Use the extension popup to send the current page URL to ADM.

Chrome:
- Open `chrome://extensions`
- Enable Developer mode
- Load unpacked and select `browser-extension/chrome`

Firefox:
- Open `about:debugging#/runtime/this-firefox`
- Select Load Temporary Add-on
- Choose `browser-extension/firefox/manifest.json`

Temporary Firefox add-ons must be reloaded after restarting Firefox. For permanent distribution, sign the Firefox extension and publish/install it through Mozilla's supported process.

## Browser bridge security

The extension uses a shared random token generated by ADM and stored in the desktop app's user data. The bridge binds to loopback only. Do not expose port 43821 to your LAN or the public internet. Do not share the token. This is a local development integration; a production release should add origin validation, rate limiting, token rotation, and a native-messaging option.

## Important limitations in this baseline

This is a working foundation, not a claim of feature parity with commercial IDM:
- Direct downloads require a server that supports HTTP downloads. Multi-connection speedups depend on server support for byte ranges and may not improve every download.
- yt-dlp supports many websites, but not every site, private content, DRM-protected streams, or every login flow. Follow the site's terms and copyright law.
- yt-dlp progress is displayed, but advanced pause/resume for a running yt-dlp process is not yet reliable across all Linux process states.
- The settings UI stores concurrency and speed preferences; this baseline applies the speed limit to newly created direct downloads, while concurrency is a follow-up integration item.
- Queue scheduling, clipboard monitoring, browser media sniffing, checksum verification, and robust restart recovery are planned enhancements.
- The browser extensions send the current tab URL. They do not yet sniff every media segment or inject an IDM-like floating download button into every website.

## Architecture

- `electron/main.cjs`: app lifecycle, aria2 process, yt-dlp process, local browser bridge, IPC and persistence.
- `electron/preload.cjs`: safe renderer API.
- `src/`: React UI.
- `browser-extension/chrome`: Chrome Manifest V3 extension.
- `browser-extension/firefox`: Firefox extension.

## Troubleshooting

### `aria2c not found`
```bash
sudo apt install aria2
```

### `yt-dlp not found`
```bash
pipx install yt-dlp
```
Ensure `~/.local/bin` is on `PATH`. For GUI-launched apps, PATH may differ from your terminal; configure the absolute executable path in a later settings enhancement if needed.

### Video merging fails
Install FFmpeg:
```bash
sudo apt install ffmpeg
```

### Browser extension cannot connect
- Keep ADM running.
- Confirm the token in extension Options matches the token shown in ADM Settings.
- Check that port 43821 is not blocked by a local firewall.
- The bridge listens on localhost only.
